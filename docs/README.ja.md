# 🚀 openclaw-ops

[🇺🇸 English](../README.md)

OpenClaw の構成・運用リポジトリです。

## 📋 前提条件

- [Homebrew](https://brew.sh/)
- [mise](https://mise.jdx.dev/)
- [pre-commit](https://pre-commit.com/)

## 🚀 クイックスタート

```bash
# リポジトリをクローン
git clone https://github.com/tqer39/openclaw-ops.git
cd openclaw-ops

# pre-commit フックをインストール
pre-commit install

# すべてのチェックを実行
prek run -a
```
