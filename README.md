# 🚀 openclaw-ops

[🇯🇵 日本語版](docs/README.ja.md)

Configuration and operations repository for OpenClaw.

## 📋 Prerequisites

- [Homebrew](https://brew.sh/)
- [mise](https://mise.jdx.dev/)
- [pre-commit](https://pre-commit.com/)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/tqer39/openclaw-ops.git
cd openclaw-ops

# Install pre-commit hooks
pre-commit install

# Run all checks
prek run -a
```
